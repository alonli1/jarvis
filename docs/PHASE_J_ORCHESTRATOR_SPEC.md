# Phase J milestone J1 — deterministic native orchestration boundary

`schedule_ready_tasks()` converts a validated plan into run-contained task
packets and declares that every leaf requires a fresh execution context. It
does not embed a model loop, route generic coding work as science, or treat a
packet as executed. A future provider adapter must consume the packet in a
fresh context, record telemetry/artifacts, and return through the Phase H/I
guards.

This narrow boundary preserves the Phase F lesson that fresh contexts and
artifact provenance matter, without claiming parity with PhysicsIntern until
representative provider-backed evaluations are available.
